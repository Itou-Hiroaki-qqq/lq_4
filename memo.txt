■使用フォントについて
「KiraMeki Pay」ロゴは画像で書き出してください。
それ以外は全てGoogleフォントになりますのでデザインデータを見た上で必要なフォントを使用してください。読み込みはlink/@importどちらでも構いません。

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Outfit:wght@100..900&family=Zen+Kaku+Gothic+New&display=swap" rel="stylesheet">

font-family: "Outfit", sans-serif;
font-family: "Zen Kaku Gothic New", sans-serif;

.outfit {
    font-family: "Outfit", sans-serif;
}
.bold {
    font-weight: bold;
}
.color-fff {
    color: #fff;
}
.color-blue {
    color: #004DA4;
}
.color-topic-blue {
    color: #003E92;
}
.color-orange {
    color: #FD5B19;
}
